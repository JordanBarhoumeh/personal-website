## Overview

This end-to-end system transforms a library of static documents into an interactive, AI-powered search application. It works as a specialised question-answering tool whose knowledge is strictly limited to the provided source documents, so every response is verifiable.

## Data preparation

Preparation is automated by a pipeline of custom scripts. Documents are stored in a database and converted into machine-readable text using AI-powered image analysis and OCR. Metadata is then enriched with AI-generated summaries, categories, authors and keywords.

## The user application

A web interface lets people ask questions in natural language. An AI search service returns synthesised answers with clickable citations back to the source. For complex queries, a Deep Research mode automates multi-step analysis: it generates follow-up questions and compiles the findings into structured reports with executive summaries, key findings and actionable insights.
