# personal-website

Jordan Barhoumeh's personal website and portfolio: experience, projects, a build-in-public blog, about and contact.

## Stack

- [Astro](https://astro.build) with React islands, MDX and Tailwind CSS 4
- shadcn/ui and Magic UI components, Motion for animation
- ShaderGradient for the hero, liquid-glass-react for glass controls

## Development

```bash
npm install
npm run dev     # http://localhost:4321
npm run build
```

Profile content lives in `src/data/profile.ts`.
